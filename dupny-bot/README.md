# Dupny Telegram Bot

Минимальный Telegram-бот проекта Dupny.

Node.js 22+, команда запуска: `npm start`.

В Railway: GitHub repo `gawvana/Telegramapp`, Root Directory `/dupny-bot`, переменные `TELEGRAM_BOT_TOKEN` и `DUPNY_SITE_URL`.

Команды: `/start`, `/help`, `/settings`, `/about`. Кнопка ведёт на сайт.

Премиум-эмодзи по гайду https://emoji.wivvi.net/, с запасным вариантом обычных эмодзи. Premium у владельца бота может требоваться по правилам Telegram.

Токен не записывать в GitHub. При компрометации менять через @BotFather.
